## Features

* User Authentication & Authorization
* Role-Based Access Control
* Store Management
* Rating System (1-5)
* Dashboard for Admin
* Dashboard for Store Owners
* User Rating Management

## Tech Stack

### Frontend

* React.js
* React Router
* Axios
* Tailwind CSS

### Backend

* Node.js
* Express.js
* JWT Authentication
* bcrypt Password Hashing

### Database

* MySQL / PostgreSQL
